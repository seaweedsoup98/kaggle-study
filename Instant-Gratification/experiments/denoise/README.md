# denoise — 라벨 노이즈 진단과 노이즈 제거 학습

**무엇을**: 학습 라벨에 섞인 무작위 flip(`make_classification` 의 `flip_y`)의 존재·비율을 진단하고,
확신 있게 라벨과 어긋나는 학습 행을 **학습에서만** 빼는 것이 성능을 올리는지 lean 위에서 잰다.

**왜**: 합성 데이터는 일부러 라벨 노이즈를 넣는다. eda/04 에서 "확신했는데 틀린 샘플 3.21%" 가 관측됐고,
뒤집힌 라벨은 QDA 의 클래스별 공분산 추정을 오염시키므로 빼면 더 깨끗한 모델이 될 것이라는 가설.

**입력**: `experiments/lean/outputs/lean_oof_train.npy` (진단), `data/loader.py` 가 찾는 train/test (학습).

## 스크립트

| 파일 | 역할 | 시간 |
|---|---|---|
| `diagnose.py` | Step 0 — 재학습 없이 lean OOF 로 노이즈 존재·비율·탐지 가능성 진단 + 합성 대조 | 40s |
| `denoise.py` | Step 1 — 내부 CV 로 노이즈를 표시해 제거/뒤집기 후 재적합. 대조군(tau=1.0)은 lean 을 비트 재현 | ~30분 |
| `denoise_synthetic.py` | Step 1-b — 진짜 라벨을 아는 합성 그룹에서 노이즈 제거의 **진짜** 효과(true-label AUC) 측정 | 1분 |

## 누수 없는 프로토콜 (denoise.py)

```
outer fold (학습 T, 검증 V) 마다:
  1. T 안에서 내부 5-fold -> T 각 행의 내부 OOF 확률        <- V 라벨을 전혀 보지 않음
  2. 내부 OOF 가 라벨과 확신 있게 어긋나는 T 의 행을 제거(또는 뒤집기)
  3. 정리된 T 로 QDA 재적합 -> V, test 예측
```

## Step 0 결과 (diagnose)

| 측정 | 결과 | 해석 |
|---|---|---|
| 확신 오답 비율 (τ 0.99 → 0.6) | 4.52% → 5.12%, 두 클래스 대칭 | τ 에 둔감 = 모델 오류가 아니라 **라벨 flip** |
| 뒤집힘 비율 추정 f = a/(a+b) | **0.0501 ~ 0.0504** (t 5개 × 양쪽 꼬리 전부) | 유효 flip 비율 **5.0%** |
| 그룹별 균일성 | 관측 sd / 이항 sd = 0.94, 그룹 AUC 와 Spearman **−0.845** | 그룹 간 균일한 무작위 flip. **그룹 AUC 편차의 정체 = 그 그룹에 걸린 flip 수** |
| 합성 대조 flip=0.05 | AUC(뒤집힌 라벨) **0.9498** / AUC(진짜 라벨) **0.9995** | 실제 0.9497 과 일치. **모델은 이미 거의 완벽, 격차는 전부 라벨 노이즈** |

5% 대칭 노이즈에서 완벽한 분류기의 AUC 상한 = 0.95² + 2·0.95·0.05·½ = **0.95**. lean(0.9497)은 상한에서 0.0003 아래.
→ 채점 라벨도 뒤집혀 있으므로, 어떤 학습 개선도 **측정되는 점수를 0.0003 이상 올릴 수 없다.**

## Step 1 결과 (denoise, 512그룹 · 4시드, 24분) — 대조군은 lean 을 비트 재현 (|diff| = 0)

| 설정 | pooled AUC | Δ pooled | Δ 그룹별 (95% CI) | 이긴 그룹 | 제거 비율 |
|---|---|---|---|---|---|
| control (= lean) | 0.949699 | — | — | — | 0 |
| drop τ=0.9 | 0.949822 | +0.00012 | **+0.00148 [+0.00118, +0.00177]** | 354/512 | 5.6% |
| flip τ=0.9 | 0.949852 | +0.00015 | +0.00146 | 342/512 | 5.6% |
| drop τ=0.9 ×2회 | 0.949822 | +0.00012 | +0.00154 | 349/512 | 5.9% |
| drop τ=0.9, reg 0.05 | 0.949851 | +0.00015 | +0.00145 | 352/512 | 5.7% |
| raw QDA / + drop τ=0.9 | 0.939301 / 0.940973 | −0.0104 / −0.0087 | −0.00916 / −0.00708 | 48 / 86 | 0 / 7.0% |

합성(진짜 라벨 채점, `denoise_synthetic.py`): lean 0.9992 → 0.9992 (변화 없음), raw QDA 0.9861 → 0.9884.

- 그룹 안 순위는 실제로 좋아진다(+0.0015 유의) — 그러나 채점 점수(pooled)로는 +0.0001, 천장 0.95 안에서의 이동이다
- 제거 비율 5.1~5.6% = 추정 f. 탐지기는 노이즈만큼만 뺀다 (합성에서 정밀도 0.92 / 재현율 0.98)
- lean 은 이미 노이즈에 강하고, 단순 모델(raw QDA)은 노이즈를 빼도 lean 과 0.009 격차 — 격차의 원인은 GMM 피처 부재
- **lean 에 넣지 않는다.** 상세와 판정은 저장소 README 7.4절, 학습 노트북은 eda/06.
